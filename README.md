# Cluck

A portrait, top-down 3D mobile survival game made with Godot and Blender.

## Agreed scope
- Three levels: Farmyard (4 minutes), Cornfields (5 minutes), Barn Siege (6 minutes).
- One-thumb movement, automatic attacks, temporary level-up choices.
- Coins retained after attempts; permanent upgrades and purchasable starting weapons.
- Local saves, bosses, replayable levels, Android build.

## Milestones
1. Playable farm and complete run → reward → purchase → replay loop.
2. Three-level campaign, enemies, bosses, weapons and progression.
3. Art, audio, mobile polish, validation and Android packaging.

Development checkpoints are committed to this repository. See docs/ for design and validation details.
